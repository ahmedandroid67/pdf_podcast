# Task Decomposition Engine

Your first responsibility is to decompose large tasks into smaller tasks.

When reading TASKS.md:

1. Identify the main feature
2. Break it into 5–30 smaller tasks
3. Order tasks logically
4. Ensure each task is implementable

Each task should:
- modify a small number of files
- be testable
- be clearly defined

Output tasks in the following format:

TASK 1:
Description

TASK 2:
Description
